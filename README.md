# C195-Software-II

Appointment Management System

A JavaScript application for scheduling and managing client appointments across international time zones.

Problem: Scheduling appointments with international clients is complicated by time zone differences, making it easy to book outside reasonable hours. This tool handles that complexity automatically.

What it does: Allows users to add, modify, and delete appointments. Accounts for international time zones to ensure appointments are scheduled within appropriate time frames. Provides an interactive menu for clients to navigate scheduling options without needing technical knowledge.

Built with: JavaScript, using time zone logic and CRUD operations for appointment and client data management.

How to run it: Clone the repo, run it with Node.js, and use the application interface to manage your appointment schedule.
